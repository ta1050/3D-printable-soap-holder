# 3D-printable-soap-holder
A simple, functional soap dish designed in SolidWorks. The model splits into two parts so it can be 3D printed easily and assembled with a bit of glue.

### How it works
* **Top Grill (`soapholder_top.SLDPRT`):** Holds the soap bar up on ribs so water drains straight through and the soap doesn't sit in a puddle and get mushy.
* **Bottom Tray (`soapholder_bottom.SLDPRT`):** Catches all the runoff water underneath so your counter stays dry.
* **Assembly:** The four legs on the top grill drop right into the corner notches on the bottom base, glued at the contact points marked with asterisks (`*`) in the CAD drawing].

### Included Files
* SolidWorks Parts 
* Exported `.3mf` files ready for slicing
